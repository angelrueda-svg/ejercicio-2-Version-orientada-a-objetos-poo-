## Descripción general

Este repositorio contiene un **ejercicio en Python** desarrollado bajo el enfoque de **Programación Orientada a Objetos (POO)**.  
El proyecto busca aplicar los conceptos fundamentales de la POO mediante el uso de **clases, objetos, atributos y métodos**, organizando el código de forma clara y estructurada.

## Conceptos aplicados

###  Programación Orientada a Objetos (POO)
El programa utiliza clases y objetos para representar entidades del sistema, permitiendo una mejor organización y reutilización del código.

###  Encapsulación
La lógica se agrupa dentro de clases, controlando el acceso a los datos mediante métodos.

###  Modularidad
El código se divide en archivos independientes, facilitando:

- Mejor organización  
- Reutilización del código  
- Mantenimiento más sencillo

## Propósito del proyecto

Este ejercicio tiene como finalidad:

- Practicar los fundamentos de la Programación Orientada a Objetos  
- Comprender el uso de clases y objetos en Python

- Servir como base para proyectos más complejos y escalables
